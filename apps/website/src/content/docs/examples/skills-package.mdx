`skills()` turns a set of agent skills into a blueprint. Each skill is a name plus its files —
`SKILL.md` and any referenced scripts or assets, nested as deeply as you like.

<Code code={code} lang="ts" title=".pjt.ts" />

Run:

```bash
pnpm pjt remodel    # writes .claude/skills/release-notes/**
pnpm pjt inspect    # exits 1 if any installed skill file was edited
```

See [Agent skills](/docs/skills/) for the layout convention, the `target` option, and how update,
swap and remove work.
