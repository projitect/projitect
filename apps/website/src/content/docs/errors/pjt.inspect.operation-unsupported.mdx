**What**: `pjt inspect` found an operation in the blueprint plan that it cannot check against the project. Today that is a post-apply command (an `Exec` operation). The error carries the operation kind and exits nonzero.

**Why**: Inspect reports drift for files only. A project with post-apply commands could be out of spec in ways inspect cannot see, so reporting "in sync" would be a false answer. It fails instead.

**How to fix**: Run `pjt remodel` to apply the plan, including its commands. To keep `pjt inspect` in CI, remove the blueprint that declares the command or wait for inspect to support commands.
