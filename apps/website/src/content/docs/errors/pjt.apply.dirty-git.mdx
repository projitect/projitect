**What**: `pjt build` is destructive — it wipes the project tree before applying. To prevent data loss, it refuses to run when `git status` shows uncommitted changes.

**How to fix**: Commit your changes (`git add -A && git commit -m wip`), then re-run `pjt build --force`. Pass `--force-dirty` only if you accept losing the uncommitted changes. (Day-to-day, you want `pjt remodel` instead — that one is non-destructive.)
