---
title: pjt.react.invalid-options
slug: errors/pjt.react.invalid-options
description: A react() option is invalid — an unknown template, or a name that is not a valid npm package name.
sidebar:
  label: pjt.react.invalid-options
---

**What**: `react()` validates its options before it plans anything. This error fires when `template` is not `"react-ts"` or `"react"`, or when `name` is empty or blank, longer than 214 characters, not lowercase, starts with `.` or `_`, contains characters that are not URL-safe, or contains a path separator other than the one in an `@scope/` prefix. The error names the offending `field` and `value`.

**Why**: `template` picks the generated files, and `name` becomes the `name` key in `package.json`. A value that npm would reject, or that could escape a directory, is refused instead of written.

**How to fix**: Use `template: "react-ts"` (the default) or `template: "react"` for JavaScript. Use a lowercase npm package name such as `my-app` or `@acme/app`. To put the app in a folder, wrap it in `directory("my-app", [react({ name: "my-app" })])`; a scoped name is not a valid folder name, so pick a separate directory name in that case.
